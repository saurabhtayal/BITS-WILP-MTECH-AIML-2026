## Setup Requirements

Most notebooks use Python 3 with Jupyter or Google Colab.

Typical requirements include:
- Python 3.x
- Jupyter Notebook or JupyterLab
- `numpy`
- `pandas`
- `matplotlib`
- `scikit-learn`
- `gspread` and `gspread_dataframe` for some notebooks

Example installation:

```bash
pip install jupyter numpy pandas matplotlib scikit-learn gspread gspread_dataframe
```

## Project and Assignment Notes

- **Python assignments**: practice exercises focused on file handling, modules, packages, and general Python programming.
- **Machine Learning notebooks**: descriptive statistics and data analysis work.
- **MFML assignments**: linear algebra and matrix-based computations such as pivot columns, solutions to linear systems, and related concepts.
- **Deep Neural Networks lab**: regression-focused experimentation using a real dataset.
- **Statistical methods materials**: companion docs supporting lecture/session topics like ANOVA.

## Getting Started
1. Clone the repository.
2. Open the notebook or HTML file for the topic you want to study.
3. Install any required dependencies before running the notebook.
4. Execute cells top to bottom.
